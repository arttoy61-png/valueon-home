# VALUEON HOME

VALUEON 본 회사 홈페이지.

## 판매형 브랜드몰 리디자인
- VALUEON 네이비 `#052E72`, 블루 `#0D73F7`, 화이트·라이트그레이 기반
- 넓은 상품 사진 위에 짧은 카피와 상품 CTA를 배치한 Hero
- 큰 카드와 작은 카드를 섞은 홈 상품 구간, 추천/전시 배지 및 가격 안내
- 설명형 3단계를 상품 상세로 연결되는 와이드 이미지·리빙 추천 섹션으로 교체
- 간결한 고객 안내와 동일한 톤의 상품 상세 상단
- 기존 상품 경로, 문의 문구, 이미지 규격 유지. 실제 판매 순위·가격·신상품 정보를 임의로 생성하지 않음

## 2026-09-26 판매형 홈 적용
- 메인: 대표상품 → 카테고리별 6개 상품 → 라이프스타일 → 구매·문의 안내
- 전체 상품 필터 및 6개 실제 상세 URL 연결
- 상세페이지: 대표 이미지, 특징, 상품정보, 구매 안내, 관련 상품
- 고객문의로 선택 상품명 전달 및 상세페이지 복귀
- 기존 연락처·문의·푸터 문구 보존 (`입력 예정` 항목은 미확정 상태 유지)
- 이미지 교체 규격과 생성 프롬프트: [IMAGE-GUIDE.md](IMAGE-GUIDE.md)
- 상품 04~06은 임시 전시 예시. 참깨강정 및 임시 상품 이미지는 AI 연출임을 표시
- 정적 페이지이며 결제·문의 접수 시스템을 추가하지 않음
- 배포: GitHub Pages, `main` 브랜치 루트. Firebase 주문·판매 시스템과 분리

아래는 초기 제작 범위 기록이며 홈의 SERVICE / 회사소개 중심 구성은 위 판매형 구성으로 대체했습니다.
