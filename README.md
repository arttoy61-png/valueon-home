# VALUEON HOME

VALUEON 본 회사 홈페이지.

## 운영 분리
- VALUEON HOME: 이 저장소
- VALUEON MAKE: 별도 저장소 `arttoy61-png/valueon-make`
- 기존 Firebase 주문/판매 시스템: 별도 운영, 이 저장소와 무관

## 현재 완료 범위
- 메인페이지
- Hero 3개 슬라이드
- SERVICE
- Featured Product
- Product 6개 그리드
- About / Notice / Customer / Footer
- ABOUT US 서브페이지
- BRAND 서브페이지
- PRODUCT 목록
- PRODUCT 상세 6개 템플릿
- COMMUNITY 공지 목록
- CUSTOMER / 1:1문의 / 제휴문의 / 오시는길 구조
- 개인정보처리방침 placeholder
- 이메일무단수집거부 placeholder
- 404 페이지
- PC / 태블릿 / 모바일 반응형
- 모바일 메뉴 / Hero 슬라이더 접근성 보완
- 상품 01~03(고구마칩 / 헤어드라이어 / 참깨강정) 메인 이미지 적용

## 실물 이미지 수령 후 교체할 항목
1. SERVICE: OVERVIEW / BRAND / PRODUCT 이미지
2. PRODUCT 04~06 이미지
3. ABOUT VALUEON 대표 이미지
4. 각 제품 상세 추가 디테일 이미지
5. BRAND 01~06 로고 또는 대표 이미지
6. 오시는길 지도/약도

## 실제 정보 확정 후 입력할 항목
- 법인명 / 대표자
- 주소
- 대표전화
- 이메일
- 운영시간
- 브랜드명 및 취급 브랜드 설명
- 실제 상품명 / 규격 / 상세정보
- 공지사항
- 개인정보처리방침 최종 문안 및 시행일
